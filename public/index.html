Planilha e grupo de mensagens não escalam quando o hub cresce.

Cada entrega atrasada, cada rota recalculada de cabeça e cada estoque de combustível estimado "no olho" é uma decisão que devia estar num painel, não numa planilha espalhada entre operadores. O Urbanlink Flow centraliza isso: uma fonte única de verdade para rotas, veículos e entregas.

Otimizador de rotas

A menor rota, calculada, não adivinhada

Escolha o hub de origem, o destino e o veículo: o motor calcula a distância pela fórmula de Haversine, aplica a penalidade de trânsito do momento e devolve tempo estimado e CO₂ evitado — antes de o veículo sair da garagem.

Mapa em tempo real

Cada veículo, visível no momento em que se move

O mapa em Leaflet mostra hubs e veículos lado a lado, com a posição de cada entrega atualizada automaticamente. Clique em qualquer ponto para ver o histórico e quem é o responsável por aquela movimentação.

Simulador de cenários

Teste a frota antes da chuva chegar

Ajuste trânsito, clima, tamanho da frota e volume de pedidos e veja, na hora, o impacto projetado no SLA e no atraso médio — útil para decidir se vale a pena reforçar a frota antes de uma sexta-feira chuvosa.

Gestão de entregas

Cadastre, edite e acompanhe sem planilha

Cadastro completo de entregas com busca, filtro por hub e status, e histórico de quem alterou o quê. O operador vê tudo; o usuário comum acompanha só o que importa pra ele.

O projeto

Um projeto integrador, pensado como produto real

Urbanlink Flow é o Trabalho de Conclusão de Curso do Técnico em Desenvolvimento de Sistemas do SENAI: front-end, back-end e banco de dados construídos do zero, para a empresa fictícia UrbanLink Systems.

  • API REST documentada, com rotas separadas por responsabilidade
  • Banco de dados relacional normalizado (PostgreSQL via Supabase)
  • Perfis de acesso separados para operador e usuário comum
  • Projeto de código aberto, versionado no GitHub
